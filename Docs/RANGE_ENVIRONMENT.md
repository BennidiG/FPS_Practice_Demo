# 现代室内靶场环境说明

日期：2026-11-16

## 原场景情况

原 Demo 并不是没有场景文件，而是已有 `StartScene` 和 `SampleScene`。其中练习场景只有 Plane、几面 Cube 墙和天空盒，缺少靶道、挡弹设施、照明层次、标识及配套设施，因此更像测试房间，而不是完整靶场。

## 新靶场布局

尺寸：**宽 20 米 × 深 22 米 × 高 7 米**，范围为 X=-10～10、Z=-21～1、Y=0～7。

### 四条靶道

- 靶道中心：X=-6、-2、2、6。
- 分隔位置：X=-4、0、4。
- 射击线：Z=-8。
- 目标生成纵深：Z=-5～-1。
- 靶道之间有高 1.3 米的矮隔墙，并提供真实 Environment 碰撞。
- 每道靶场后方均有独立橡胶挡弹板和钢框。

挡弹板中心 Y=3.35、高 6.7，能够覆盖现有目标中心 Y=2～6 及半径 0.65 米的完整范围。

### 建筑与装饰

- 混凝土地面和墙体；
- 深色下部护墙板、结构柱和顶梁；
- 墙面吸音板、通风管及格栅；
- 地板通道线、黄色射击线和警示条；
- 靶道编号 01–04 与 SHOOTING RANGE 标识。

### 配套设施

- 后方控制台、三个显示屏和操作按钮；
- 两张后方凳子；
- 控制台和凳子均按实际模型位置配置碰撞，避免空气墙。

### 照明

- 五排顶部灯具；
- 三组无阴影 Point Light，覆盖前、中、后区域；
- 冷色灯光、弱方向光和平面环境光；
- 不再让室内主要受星空环境光照明。

## 性能设计

- 环境网格为 **14,144 顶点 / 6,424 三角形**，低于 15,000 顶点预算。

- 可视环境由 `RangeModelFactory` 合并为一个九子网格，而不是为每个零件创建独立渲染对象。
- 原 Plane/Wall 只保留匹配的碰撞，不再重复渲染。
- 仅矮隔墙、控制台和凳子新增六个 BoxCollider。
- 环境网格只初始化一次，重新启用组件不会重复生成。
- 生成的子对象使用 `HideFlags.DontSave`，不会污染场景序列化。
- 点光源不投射阴影，控制实时照明成本。
- 本机离线代码构建微基准约为 **0.798 ms/次**，只在初始化执行，不在射击路径执行。

## 验证

最终五轮回归均为 PASS：每轮 195 项资源/静态检查与 11 个核心测试，累计 **975 项次检查、55 项次核心测试**。

- 九个子网格均有有效三角形和坐标。
- 场景 GUID、材质、碰撞边界和组件引用通过检查。
- PlayMode 测试验证环境只生成一次、三组灯光、六组设施碰撞以及控制台/凳子位置。
- 原有射击、移动、武器切换和靶子生成功能保留。

最终回归结果和 Unity 原生测试限制见本文件末尾“验证边界”。## 验证边界

当前机器没有 Unity 2021.3.8f1c1 编辑器，因此实际光照、材质、阴影、视角构图和 GPU 帧率仍需在 Unity 中验收。离线网格和代码检查不能替代真实画面与运行性能。
