# FPS Practice Demo 性能审查报告

日期：2026-11-16

## 1. 结论

代码审查确实发现了可能造成命中间歇性卡顿的热点，主要集中在靶子碰撞体重建、重复物理同步和 HUD 字符串分配。上述问题已修复，并完成五轮回归。

当前代码中已经没有以下射击路径行为：

- 命中时 Instantiate/Destroy 目标；
- 命中时重建视觉网格；
- 每次重新激活靶子时重设 MeshCollider 并强制重新烘焙；
- 切换武器时重建武器网格；
- 每次 OnGUI 都重新拼接 HUD 字符串；
- 命中停用时额外执行一次全局 Physics.SyncTransforms。

因此，**没有再发现明显的、每次命中都必然产生的大型 CPU/GC 热点**。但当前机器没有 Unity 编辑器，不能据此保证所有设备上都没有帧率下降、物理耗时峰值或 GPU 卡顿。

## 2. 已修复的性能问题

### 碰撞体重建风险

原 `TargetVisual.OnEnable` 在靶子每次重新激活时执行：

- 给 MeshFilter 赋值视觉网格；
- 将 MeshCollider.sharedMesh 先设为 null，再重新赋值。

命中重生会反复启用/停用靶子，这可能触发重复碰撞体初始化和 PhysX cooking。

修复后：

- 每个 TargetVisual 实例只初始化一次，重新激活直接返回；
- 视觉网格与碰撞网格分离；
- 视觉网格保留 1,568 顶点的细节；
- 碰撞网格使用相同圆形外轮廓的轻量 32 边圆柱，约 320 顶点，顶点数减少约 80%；
- 不再通过 `sharedMesh = null` 强制重建。

### 物理同步

- 移除靶子命中停用和生成失败时的额外 `Physics.SyncTransforms()`。
- 仅在目标移动并重新激活后同步一次，保证下一次射线使用正确位置。
- 默认 0.2 秒延迟重生保留，物理同步通常不在命中同一帧执行。

### HUD GC

- 命中统计只在射击数/命中数变化时格式化。
- 武器文本只在武器、弹药、换弹或切换状态变化时更新。
- OnGUI 仅使用缓存文本，不再每次事件都拼接字符串。
- 性能文本最多每 0.25 秒更新一次。

### 模型与切换

- 靶子和武器网格只在初始化时构建。
- 步枪和手枪模型预先创建，切换只 SetActive，不重新生成网格。
- 武器状态机没有每次射击的对象分配需求。

## 3. 离线微基准

执行：

```powershell
powershell -ExecutionPolicy Bypass -File Tools/performance-benchmark.ps1
```

本机最近一次结果：

| 项目 | 平均构建耗时 | 平均托管分配 |
| --- | ---: | ---: |
| 步枪网格 | 0.467 ms | 648.1 KiB |
| 手枪网格 | 0.205 ms | 318.7 KiB |
| 靶子视觉网格 | 0.121 ms | 146.3 KiB |
| 靶子轻量碰撞网格 | 0.017 ms | 32.7 KiB |
| 靶场环境网格 | 0.798 ms | 1173.7 KiB |

- 每种网格执行 100 次构建取平均。
- 这些构建只发生在初始化，不在每次射击时执行。
- 武器状态机执行 1,000,000 次操作约 5.8 ns/次，线程累计分配约 40 bytes，未显示实际 GC 压力。

**注意：**微基准使用离线 Unity API 测试桩，只衡量托管代码构建和状态操作。它不包含 Unity Mesh 上传、PhysX cooking、Raycast、渲染、GPU 驱动或真实帧时间，不能换算成游戏 FPS。

## 4. 游戏内实际性能监测

在练习场景按 **F8** 打开/关闭性能面板。打开时会清零统计，避免启动初始化耗时污染射击测量。

显示内容：

- 平均帧耗时、最差帧耗时；
- 超过 33.33 ms 的帧数；
- 最近一次及最差射击执行耗时；
- 最近一次及最差目标重生执行耗时。

射击计时包括射线、命中处理、后坐力和当帧重生；延迟重生会单独计入 Respawn 指标。

建议：

- 60 FPS 的预算为 16.67 ms，30 FPS 为 33.33 ms。
- 若普通帧稳定，但 Shot/Respawn 峰值明显且与卡顿同步，应重点检查 PhysX、碰撞体和场景同步。
- 若 Shot 很低但画面仍卡顿，应继续检查 GPU、材质、阴影、驱动和后台进程。
- 若周期性卡顿与 GC 同时出现，使用 Unity Profiler 的 GC Alloc 和 Memory 模块复核，而不是只看平均 FPS。
